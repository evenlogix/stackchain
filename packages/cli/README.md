# @evenlogix/stackchain-cli

Generate production-ready software foundations.

```bash
npm install -g @evenlogix/stackchain
# or
npx @evenlogix/stackchain-cli create flutter my_app --org com.company -y
```

Also published as [`@evenlogix/stackchain`](https://www.npmjs.com/package/@evenlogix/stackchain) for `npm i -g @evenlogix/stackchain`.

## Commands

```bash
stackchain create flutter <name>
stackchain add feature|screen|widget|model|repository|datasource|usecase|service <name>
stackchain plugin install|list|uninstall|official
stackchain doctor
```

See the [monorepo README](https://github.com/evenlogix/stackchain#readme) for architecture and plugin docs.
